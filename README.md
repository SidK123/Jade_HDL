# Jade HDL

We'll be building out a language, compiler, simulator, and FPGA place and route tool from scratch. Think of this as a giant fuck you to AI (not a single line of code will be AI-generated). I hope this language will be a little easier to use than SystemVerilog, and I plan on it existing at a higher level of abstraction. Not quite HLS, because we all know how that goes, but just more constructs to work with that express commonly used hardware paradigms. Still haven't thought it completely through, but definitely want to do something.
